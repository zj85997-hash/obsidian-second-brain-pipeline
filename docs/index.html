第二大脑汇聚管线

开会录音、课堂转写、飞书方案、随手记的备忘录，散在四个地方，要用的时候谁也找不到。这套脚本把它们汇进同一个 Obsidian 库，按项目线自动分类，自动生成首页和案例目录。

查看源码 5 分钟试跑

一条命令走完四步

① 采集得到大脑 · 钉钉听记
飞书文档 · 苹果备忘录
→
② 收件箱统一成带标题、日期、
来源的 Markdown
→
③ 分类入库按规则放进
「项目线 / 案例」
→
④ 目录页首页、板块总览、
案例时间线

日常只跑 python3 -m sbp sync；每一步也能单独跑。

能做什么

📥 四个来源汇到一处

录音转写、会议逐字稿、云文档、备忘录。增量采集，同一条不会重复，中断了重跑会接着来。

🗂 按项目线自动分类

人工指定、标题规则、正文规则依次匹配，都认不出来的进「待归类」。

✍️ 不动你手写的内容

默认只新增笔记，不删除、不覆盖；目录页只更新自动生成的那一段。

🕶 一键代号化

人名换成 A001、公司换成 P01，导出一份能拿给别人看的副本，文件名一起改，双链不断。

5 分钟试跑不需要任何账号，演示数据全部虚构

git clone https://github.com/zj85997-hash/obsidian-second-brain-pipeline.git
cd obsidian-second-brain-pipeline
python3 -m sbp demo --out ./sbp-demo     # 用 Obsidian 打开 sbp-demo/vault
  1. 把 config.example.json 复制成 config.json，写上你的项目线和分类规则
  2. 登录各家官方命令行工具（getnote、dws）；飞书建一个只读应用，设好环境变量后运行 feishu-auth
  3. 先 import --dry-run 预览每篇会放到哪里，没问题再正式入库

安全与隐私

🔑 代码里没有凭据

登录交给官方工具；飞书凭据只从环境变量读，令牌文件只有你自己能读。

🔒 证书校验始终开启

公司网络用自签证书时，指定证书文件即可，不需要关掉校验。

💻 笔记只在本机

零第三方依赖，不上传任何笔记；个人配置、收件箱和库都在 .gitignore 里。
